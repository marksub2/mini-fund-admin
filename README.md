# Mini Fund Admin

펀드 사무관리 시스템의 핵심 업무(거래 관리, 금액 계산, 기준가 산출)를
단계적으로 직접 구현해 보는 Java 프로젝트입니다.

## 현재 구현 내용 (0단계)

- **펀드와 거래 구성**: 펀드 이름과 거래 목록(종목명, 수량, 단가)을 가진 `Fund`, `Trade` 클래스
- **금액 합계 계산**: 거래별 금액(수량 × 단가)을 구하고, 펀드 안의 모든 거래 금액을 합산
- **정확한 금액 계산**: `double` 대신 `BigDecimal` 사용
- **입력값 검증**: 수량이 0 이하인 거래는 생성 단계에서 예외로 차단

## 설계 포인트

### 왜 `BigDecimal`인가

`double`은 2진 부동소수점이라 0.1을 정확히 표현하지 못합니다.

```java
3 * 0.1                                            // 0.30000000000000004
BigDecimal.valueOf(3).multiply(new BigDecimal("0.1"))  // 0.3
```

펀드 시스템에서는 이런 미세한 오차가 수많은 거래에 걸쳐 쌓이면
기준가 오류나 잔고 대사 불일치로 이어지기 때문에, 금액은 모두 `BigDecimal`로 계산합니다.

### 왜 생성자에서 검증하는가

수량 검사를 `Trade` 생성자 맨 앞에 두어, 잘못된 거래 객체가 아예 만들어지지 않게 했습니다.
`Fund`에서 검사하면 `Fund`를 거치지 않는 경로로 잘못된 거래가 생길 수 있기 때문입니다.

## 실행 예시

```
수량은 0보다 커야 합니다: 0
57.8
```

수량 0인 거래는 차단되고, 나머지 세 거래의 금액 합계가 출력됩니다.
